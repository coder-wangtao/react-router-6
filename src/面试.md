2.Context 做数据共享 navigator === history ，location(当前位置、当前路由) useLocation 就是获取这个 location

3.Route(代表每一个路由)，会转换成一个树形结构[{element:'',path:'',children:[]}] 类似与 dom -> vdom

4.因为我们在 Route 中定义的 path 都是相对路径，所以我们在 matchRoutes 方法中，需要对 routes 对象遍历，
对于 children 里面的 path 需要变成完整的路径，并且需要将 routes 扁平化，不在使用嵌套结构

5.匹配中的 matches,reduceRight 采用从右往左的遍历顺序，将上一项的返回值作为后一项的 outlet，那么子路由就作为 outlet 传递给了父路由,
<OutLet/> => useOutLet => 获取 context 上的 outlet(子路由) useParams 获取 context 上的 matches
